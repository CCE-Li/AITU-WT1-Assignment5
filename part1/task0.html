Task 0. First Script

This page includes an external JavaScript file. The script prints the student's name and group with console.log() and shows a friendly alert when the page loads.

What happens on load

  • An alert dialog with the message “Hello, JavaScript World!” appears.
  • Open the browser DevTools with F12 and switch to the Console tab to read the printed name and group.

The included script

Linked from this page with <script src="../js/task0.js"></script>
